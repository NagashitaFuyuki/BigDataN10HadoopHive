01

Khởi tạo Docker

Tạo container hadoop-master từ Ubuntu 22.04, cấu hình RAM, SSH và mở đầy đủ các cổng (9870, 8088, 10000).

02

Cấu hình Hadoop & Hive

Giải nén Hadoop 3.3.6, Hive 4.0.1, nạp hadoop-hive-env.sh, cấu hình XML (MapReduce, YARN, Derby Metastore).

03

Khởi động Dịch vụ

Format NameNode, chạy HDFS, YARN, kiểm thử MapReduce pi và khởi động HiveServer2 lắng nghe cổng 10000.

04

Nạp Dữ liệu & Truy vấn

Đưa dataset từ Windows lên HDFS, sửa hàm str_to_map, chạy file SQL 00–07 trong Beeline và kiểm tra 25 bảng.
