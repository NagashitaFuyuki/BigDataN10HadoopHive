Khung có nhãn PowerShell chạy trên Windows, nhãn Beeline chạy trong cửa sổ Beeline. Bấm Copy ở mỗi khối rồi dán vào cửa sổ tương ứng.

3Số dòng cần thấy

Các con số hướng dẫn nêu rõ. Các bảng còn lại bạn tự đối chiếu bằng SELECT COUNT(*).

4Truy vấn mẫu

Các câu lệnh theo từng file, kèm giải thích ngắn: file 05 (kiểu dữ liệu phức hợp) và file 07 (truy vấn thực hành). Chạy trong Beeline sau USE N10Hive;.

5Xóa để làm lại từ đầu

Dùng khi cần quay lại video hoặc nạp lại dữ liệu. Chạy trong PowerShell, từ phần đã làm tới phần chưa làm.

6Những chỗ dễ vấp

1Không cần gõ CREATE DATABASE bằng tay nếu đã chạy file 00. Hai cách cho cùng kết quả.
2LOAD DATA INPATH di chuyển file trên HDFS vào kho của Hive. Muốn nạp lại, chạy lại lệnh hdfs dfs -put -f trước.
3HDFS phân biệt hoa thường. File gốc viết hoa (CTDON.tsv), file mở rộng viết thường (don_morong.tsv). Đường dẫn trong file 02 và 04 phải đúng như vậy.
4Trang này đánh số lại truy vấn mẫu theo file: 05.1 đến 05.5 và 07.1 đến 07.7. Hướng dẫn gốc ghi các truy vấn của file 07 là 6.1 đến 6.7 và có hai mục đều là 6.5; mục thứ hai (thống kê theo thiết bị) là 07.6 trong trang này.
5Lỗi Invalid function map_from_entries: hàm này không có trong Hive 4.0.1. Bước 4 đã có lệnh sed thay bằng str_to_map. Nếu bạn chạy lại docker cp .\sql\., file 05 bị chép đè về bản gốc nên phải chạy lại lệnh sed đó.
6Truy vấn INSERT vào bảng STORED AS ORC báo return code 2 và log YARN có Internal.checkNotNull: do xung đột Protobuf. Cách xử lý nằm ở mục 7b của hướng dẫn cài đặt Hadoop/Hive (hai property hive.aux.jars.path và mapreduce.job.user.classpath.first).
